# KhojSewa

KhojSewa is a simple lost and found web application built to help people report lost items and help others return found items to their rightful owners.

The idea is straightforward: users can post details of items they’ve lost or found, browse existing posts, and contact each other to exchange information.

This project was mainly built to understand how a full-stack MERN application works end to end.

---

## Tech Stack

- Frontend: React, JavaScript, HTML, CSS  
- Backend: Node.js, Express (basic APIs)  
- Database: MongoDB  
- Tools: Git, GitHub,

---

## Features

- Create posts for lost and found items  
- View and browse items posted by other users  
- Basic form handling and validation  
- REST API integration between frontend and backend  
- Data stored and retrieved from MongoDB
